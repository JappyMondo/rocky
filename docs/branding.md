# Rocky color palette

Rocky's light theme is inspired by RAL 5015 (sky blue). The digital base is
`#007CB9`, selected as a readable web approximation rather than a physical
paint conversion.

| Role | Value |
| --- | --- |
| Brand / primary action | `#007CB9` |
| Hover / active | `#00679C` |
| Brand text | `#00517D` |
| Focus indicator | `#00517D` |
| Soft blue surface | `#E6F3FA` |
| Blue border | `#B8DCEC` |
| App background | `#F7FAFC` |
| Neutral surface | `#FFFFFF` |
| Primary text | `#172B3A` |
| Muted text | `#526574` |

The primary action, focus, and brand-text shades provide readable contrast on
their intended light or white surfaces. Blue communicates Rocky branding only:
success, warning, error, workflow categories, syntax, and diff additions and
deletions retain their distinct semantic colors. The raccoon logo retains its
original rendered green and cream colors.
