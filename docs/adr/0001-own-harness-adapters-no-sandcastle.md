# Own Harness adapters instead of Sandcastle

The map originally pinned Sandcastle as a wrapped hard dependency for driving agent CLIs. By the time the harness abstraction was settled ([NG-579](https://linear.app/digimondo/issue/NG-579)), Rocky had already routed around it for worktrees, structured output and session resume ([NG-574](https://linear.app/digimondo/issue/NG-574)), and the capability audit ([NG-568](https://linear.app/digimondo/issue/NG-568)) found host mode skips permission gating, drops per-Agent env, reports no usage in our mode, and that upstream has been paused since 2026-06-29. What the library still did for Rocky — spawn a harness CLI and parse its stream — Rocky needs to own anyway, because Steering requires detecting turn boundaries in that same stream.

We therefore drop Sandcastle entirely: Rocky ships its own Harness adapters (spawn, stream-parse, session-resume, usage extraction), exactly claude-code and opencode in v1. A third harness is a code contribution, not configuration — an untested stream parser is broken, not degraded. Consequence: `ctx.sandbox` is deleted (there is no library underneath to escape into); `ctx.exec` is the escape hatch, and a plugin adapter interface is explicitly deferred.

**Amendment (2026-09-07, NG-530/628/647).** The adapter also owns `checkAuth`; Doctor resolves it, and Preflight must use that same adapter rather than a parallel auth seam. An offline login probe establishes credential availability, not inference eligibility. Claude session isolation cannot silently use a different keychain account: Doctor probes that isolation too and names the configured token/API-key fix when needed.

OpenCode's per-Harness `sessionStorage` is `rocky` by default, with the explicit `opencode` alternative. The first keeps its native resumable database alongside the Run's Transcript; the second respects OpenCode's ordinary native store (including a configured `OPENCODE_DB`). The raw Transcript stays in the Run in both modes. Native caches and logs are not the Transcript and are not relocated by this setting. This is a deliberate retention exception for developers who want ordinary OpenCode history, not permission to share conversations between Steps. See [the configuration and verification contract](../harnesses.md).
