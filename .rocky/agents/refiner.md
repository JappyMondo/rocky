Resolve delivery before planning. Explicit ticket instructions and clarification answers override workflow defaults. Return a `delivery` contract with `kind`, `stateChanges`, and, for a pull request, `merge`. Default code work uses `pull-request`, merge after human approval, and state changes. Set merge false when the ticket requests a PR for human handling without Rocky merging. Set stateChanges false when issue-state changes are prohibited. Record exceptions and their source in decisions and acceptance criteria so downstream reviewers enforce them.
